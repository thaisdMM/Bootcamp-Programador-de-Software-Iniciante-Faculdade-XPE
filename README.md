# 🖥️ Beginner Software Developer Bootcamp

This repository contains the studies from the Beginner Software Developer Bootcamp at XPE College, focusing on the fundamental concepts of programming logic and the basics of three different programming languages: Java, Python, and JavaScript (Front-End Development).

#### 🚀 Practical Learning

The main goal of this bootcamp was to introduce programming logic and help develop practical skills in various programming languages.

#### 🏆 What was learned

### 1️⃣ Fundamentals (32h)
	•	Introduction to Computers
	•	Introduction to Programming Logic
	•	VisuAlg and Portugol
	•	Variables and Data Types
	•	Operators and Input Data
	•	Decision Structures
	•	Boolean Logic
	•	Lists
	•	Loops
	•	Functions and Procedures

	📁 Note: Even though this part of the course was completed, I opted not to include the exercises from VisuAlg and Portugol in this repository.

### 2️⃣ Java (32h)
	•	Introduction to Java
	•	Java vs JavaScript
	•	Java Applications
	•	Setting up the Java Development Environment
	•	Data Types, Variables, and Comments
	•	Decision Structures
	•	Loops
	•	Methods
	•	Classes and Objects

### 3️⃣ Python (32h)
	•	Introduction to Python
	•	Python Data Types
	•	Libraries and Basic Operations
	•	Solving Simple Algorithms with Python

### 4️⃣ Front-End Fundamentals (32h)
	•	How Web Applications Work
	•	Front-End vs Back-End
	•	HTML: Elements, Tags, Attributes, Forms, and Semantic HTML
	•	CSS: Selectors, Flexbox, and Grid Layout
	•	JavaScript:
	•	Variables (var, const, let)
	•	Decision and Loop Structures
	•	Functions and Events
	•	Array Methods, Spread/Rest Operator, Destructuring
	•	Template Literals, Default Parameters
	•	HTTP Requests with Fetch, Promises, and Async/Await

#### 🏁 Final Challenge (16h)

The final challenge was to develop a more complex program using any of the languages learned during the bootcamp.
